- [transport.md](transport.md): Broker 連線與傳輸層責任
- [protocol.md](protocol.md): USP 訊息組包、解析與回應處理
- [scripting.md](scripting.md): 測試腳本執行與參數化流程
- [interface.md](interface.md): GUI / Daemon / IPC 介面分工
