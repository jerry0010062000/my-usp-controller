# 1. 初始化設定：縮小預設 Pool 1 的範圍

# [確認設定]
Device.DHCPv4.Server.Pool.1.?0


# ===================================================================
# 2. 新增測試 Pool：MAC 位址完全匹配綁定

# [ba-cli 指令 - 新增並同時設定參數]
Device.DHCPv4.Server.Pool.+{Enable=true, Interface="Device.IP.Interface.3.", MinAddress="192.168.1.10", MaxAddress="192.168.1.12", SubnetMask="255.255.255.0", Chaddr="b0:75:0c:e1:69:9b", ChaddrExclude=false, ChaddrMask="FF:FF:FF:FF:FF:FF"}

# [確認設定 - 使用搜尋路徑以確保定位到正確的實例]

# ===================================================================
# 4. 修改 Pool：測試 ChaddrExclude (排除模式)

# [ba-cli 指令]

# [確認設定]
Device.DHCPv4.Server.Pool.[Chaddr=="b0:75:0c:e1:69:9b"].ChaddrExclude?


# ===================================================================
# 5. 修改 Pool：測試 ChaddrMask (OUI 範圍匹配)
# ===================================================================

# [ba-cli 指令]
Device.DHCPv4.Server.Pool.[Chaddr=="b0:75:0c:e1:69:9b"].{ChaddrExclude=false, ChaddrMask="FF:FF:FF:00:00:00"}

# [確認設定]
Device.DHCPv4.Server.Pool.[Chaddr=="b0:75:0c:e1:69:9b"].{ChaddrExclude, ChaddrMask}?

# 6. 清理環境
# ===================================================================
